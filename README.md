# Gesture-Controlled RC Car

Control an Arduino UNO R4 WiFi RC car with hand gestures. A laptop app reads your hand through a webcam (OpenCV + MediaPipe) and sends commands over local WiFi (UDP).

**Status:** Phase 0 - environment setup

## Planned phases

1. Arduino basics
2. Drive motors through the HW-130 shield
3. UNO R4 WiFi networking (UDP)
4. Car firmware with failsafe
5. Hand tracking
6. Gesture recognition
7. Integration
8. Desktop app
9. Testing and docs
